# Byesar Community

**Live demo:** https://byesar-community-demo.vercel.app/c/demo-prayer (also `/c/demo-mosque`; add `?lang=ar` for Arabic). Demo only: data may be reset at any time.
Forum engine for Muslim creators: Q&A, votes, anonymous posting, EN/AR right-to-left, halal moderation, and many product spaces on one engine. Status: being built, private. Built on the MIT-licensed Makerkit Lite starter (see THIRD-PARTY-NOTICES.md).
