# Security Policy

## Reporting a vulnerability

Please report security problems privately using GitHub's private vulnerability reporting:

1. Open the **Security** tab of this repository.
2. Choose **Report a vulnerability**.
3. Describe the problem, how to reproduce it, and what you think the impact is.

Please do not open a public issue or pull request for a vulnerability, and do not post details anywhere public until it has been fixed.

Never include real secrets, other people's personal data, or data from a live site you do not own in your report.

## What to expect

This is a small open-source project run by maintainers in their own time. We will try to acknowledge a report and keep you updated in the advisory thread, but we cannot promise fixed response times. When a fix is released we will credit you in the advisory if you want that.

## Scope

Reports about this repository's code are welcome, for example bypassing the write gate (rate limit, captcha, validation, moderation hold), reading unapproved content, or exposing server-side keys.

Problems in third-party services or in the Makerkit Lite starter itself should go to those projects, although you are welcome to tell us if they affect this repository.

## Supported versions

Only the latest code on the `main` branch is supported. There are no maintained older release lines.
